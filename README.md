# Dos Santos Miami

DISEÑA Y DESARROLLA UNA PÁGINA WEB PREMIUM PARA “DOS SANTOS – FINE MIAMI FARE”, UTILIZANDO EL LOGO PROPORCIONADO COMO REFERENCIA PRINCIPAL DE IDENTIDAD VISUAL.

LOGO:

Utiliza EXACTAMENTE el logo proporcionado de DOS SANTOS como elemento principal de branding.

El logo debe aparecer de forma visible y elegante en:

- Navbar/header, en tamaño adecuado

- Hero section, como elemento protagonista

- Footer

- Sección “Our Story” cuando sea visualmente apropiado

NO rediseñes el logo.

NO cambies sus personajes.

NO cambies sus colores.

NO deformes ni estires el logo.

Mantén siempre sus proporciones originales.

El logo debe sentirse integrado naturalmente dentro de la página y no como una imagen pegada encima del diseño.

PALETA DE COLORES:

Deep Miami Blue — #075B8E

Midnight Navy — #071B2A

Vibrant Fuchsia — #E50070

Miami Gold — #E7B84B

Warm Cream — #FFF8E8

White — #FFFFFF

Usa principalmente Warm Cream, White y Deep Miami Blue.

Utiliza Fuchsia y Gold como colores de acento.

DIRECCIÓN VISUAL:

La página debe combinar:

MIAMI + FOOD + FAMILY + PREMIUM + FUN

Inspiración:

- Restaurantes modernos de Miami

- Editorial gastronómico

- Branding vintage moderno

- Ilustración del logo

- Cultura y energía de Miami

La web NO debe parecer una plantilla genérica de restaurante.

NAVBAR:

Navbar moderna y limpia.

Izquierda:

LOGO DE DOS SANTOS

Centro/derecha:

HOME

MENU

OUR STORY

GALLERY

CONTACT

Botón destacado:

“ORDER NOW”

Navbar sticky al hacer scroll.

Cuando el usuario haga scroll, el navbar debe cambiar sutilmente de transparente a Midnight Navy o White para mantener excelente legibilidad.

HERO SECTION:

Crear un hero espectacular de pantalla completa.

Utilizar fotografía gastronómica profesional de comida recién preparada, con ambiente cálido y sofisticado de Miami.

Colocar el LOGO DE DOS SANTOS de manera prominente pero elegante.

Headline:

“MIAMI HAS A FLAVOR.”

Texto secundario:

“Fine food. Great vibes. Made for Miami.”

Botones:

“VIEW MENU”

“ORDER NOW”

Agregar detalles gráficos inspirados en el logo:

- líneas doradas

- curvas

- pequeños elementos ilustrados

- formas circulares

- detalles fucsia

Mantenerlos sutiles.

Título:

“OUR STORY”

DISEÑO RESPONSIVE:

La página debe estar perfectamente optimizada para:

- Desktop

- Tablet

- Mobile

En mobile:

- logo claramente visible

- menú hamburguesa

- botones grandes y fáciles de tocar

- fotografías optimizadas

- excelente legibilidad

- navegación rápida
